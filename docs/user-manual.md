# User Manual

Everything you need to run Agentimus as a site owner — no code required. These pages walk you from installing the plugin to getting every feature working, in plain language.

New here? Read them roughly in order:

1. **Overview** — what Agentimus does and why it helps.
2. **Installation & first run** — get set up in a couple of minutes.
3. **Dashboard & activity log** — see AI traffic and what agents are doing.
4. **Readiness report** — your AI-readiness scorecard, with one-click fixes.
5. **Machine-readable outputs** — llms.txt, Markdown, discovery docs, sitemap.
6. **Structured data (JSON-LD)** — the Schema.org your pages emit.
7. **Identity setup** — tell AI who you are and what you do.
8. **Topics for AI** — say what each page is about.
9. **Agent preview** — see exactly what an agent receives.
10. **AI access & crawler controls** — who may crawl, and how.
11. **Exposure & hardening** — optional privacy tightening.
12. **AI Visibility monitoring** — track whether AI engines cite you.
13. **Privacy & external services** — what leaves your server (almost nothing).
14. **FAQ** — quick answers to common questions.

Use the sidebar to jump to any page.
